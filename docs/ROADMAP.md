# Backend Roadmap

This repo's build order was originally mapped 1:1 onto the 20-week personal
FastAPI learning curriculum (`docs/FastAPI-Roadmap.html`). In practice the
work done diverged from that week numbering early on, so the step-by-step
roadmap — kept in sync with actual git history — now lives in one place:

> **`../../docs/ROADMAP.html`** — the integrated master roadmap: product
> phases, the real backend build order (steps 1–29), and the future
> frontend (Emma) / panel tasks mapped to the backend milestones they
> depend on.

Curriculum rule still applies: **steps 1–9 — no AI, you write the code.
Step 10 onward — AI can write it, you review it.**
